# Public Opinion

面向舆情监测、事件分析与智能决策支持的多模态信息分析平台。

## 项目简介

网络信息分散在新闻网站、社交平台与短视频平台，内容形式多样、传播变化快，人工检索与整理难以持续跟踪事件全貌。Public Opinion围绕主题与事件组织信息采集、内容分析和报告生成，为舆情跟踪、热点研判与信息查询提供统一的工作入口。

平台覆盖“创建监测任务—采集相关信息—分析事件动态—生成舆情报告—查看与追问”的业务流程，主要功能包括：

- **多源信息采集**：围绕关键词与监测主题汇集新闻及社交平台信息，进行清洗、转换与存储。
- **舆情与事件分析**：结合文本情感分析、事件聚类与模型分析，辅助整理公众态度和事件动态。
- **可视化展示**：通过图表与内容列表呈现分析结果，支持查看相关信息。
- **报告生成**：将采集内容与分析结果组织为舆情报告，辅助复盘与研判。
- **智能问答**：围绕相关内容进行自然语言查询与追问，辅助理解事件信息。
- **多端访问**：通过Web与移动端查看任务、分析结果及报告。

## 技术演进

### V1.0 · Public Eye（天眼）

围绕基础舆情监测流程建设采集、分析与展示能力，技术重点为多源数据采集、NLP情感分析及事件聚类。

源码：[public-eye](./public-eye/)

### V2.0 · InsightMon（智眸）

逐步拆分采集、业务与模型处理模块，扩展智能分析与自动化报告能力。

| 层次 | 主要技术 |
| --- | --- |
| 前端 | Vue 3、Vite、Vue Router、Element Plus |
| 可视化 | ECharts、Chart.js、词云 |
| 后端与服务化 | Java、Spring Boot、Spring Cloud、Spring Cloud Alibaba |
| 数据访问 | MyBatis-Plus、MySQL |
| 采集与分析 | Python、独立采集与模型模块 |

源码：[insightmon](./insightmon/)

### V3.0 · SignalX（讯息流谱）

在任务管理、数据采集、报告与问答能力的基础上，引入移动端工程，继续扩展智能处理与多端协同。

| 层次 | 主要技术 |
| --- | --- |
| 前端 | Vue 3、Vite、Vue Router、Vant |
| 移动端 | Capacitor、Android |
| 内容展示 | ECharts、Markdown渲染 |
| 业务后端 | Java 17、Spring Boot 3、MyBatis-Plus |
| 数据与缓存 | MySQL、Redis |
| 采集与模型调用 | Python、Flask、模型API客户端 |
| 接口与资源管理 | OpenAPI、JWT、对象存储SDK |

源码：[signalx](./signalx/)

## 开始使用

```bash
git clone https://github.com/CXQ7/public-opinion.git
cd public-opinion
```

进入所需版本目录，按照对应README准备依赖、配置环境并启动服务。
